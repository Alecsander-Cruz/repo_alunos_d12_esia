Diagnóstico sem nota

Não vale nota nem presença. Serve para o professor calibrar o ponto de partida. Responda em poucas linhas, com sinceridade, até 16/10, 18h, pelo canal informado.

  1. Há quanto tempo você programa profissionalmente e em quais linguagens?
  2. Você lê Python com facilidade? (Muita / Alguma / Pouca.) Isso não é pré-requisito: o código do caso é curto.
  3. Você usa git no dia a dia (branch, diff, commit)? (Sim, com segurança / Sim, o básico / Não.)
  4. Que ferramentas de IA para código você já usou? (Completar no editor / Chat / Edição com escopo / Agente com acesso a arquivos e terminal / Nenhuma.)
  5. Pense na última vez que a IA gastou mais tempo seu do que economizou. O que aconteceu em uma frase?
  6. Você já aceitou código gerado sem ler tudo? O que aconteceu depois?
  7. Seu time escreve testes? Eles costumam falhar quando alguém quebra algo? (Quase sempre / Às vezes / Raramente.)
  8. Você já revisou um pull request gerado por IA ou por um colega usando IA? O que mais te preocupou?
  9. Seu ambiente permite instalar Python e rodar scripts? Se não, em que condição você fará as práticas?
  10. Que dúvida ou expectativa você leva para a disciplina?

A resposta ao item 9 define quem usará o caminho textual desde o bloco 1.
